# NOVA AI — отчёт безопасности

2026-11-11. Это обзор кода и ограниченные регрессионные проверки, не внешний пентест и не гарантия отсутствия уязвимостей.

## Исправлено

1. Серверные purchase/refund транзакции не читают PostgreSQL `void` через Prisma queryRaw. Блокировка, начисление и запись receipt атомарны; проверены повторы и чужая привязка аккаунта.
2. Дедупликация списания выполняется под блокировкой кошелька. Платная операция требует согласованной цены; неуспешный AI не списывает баланс.
3. Неполный SSE без маркера завершения не принимается за успешный ответ. Закрытие Android stream выполняется вне UI-потока; при Stop интерфейс не обещает отсутствие списания, если commit успел завершиться раньше отмены.
4. JWT ограничен HS256. Обновлены @fastify/jwt до 10.2.7, zod до 4.6.7, googleapis до 189.0.0; deepmerge-ts зафиксирован override 8.0.0 для Prisma CLI. После обновлений прошли Prisma build и тесты.
5. Docker удаляет devDependencies после сборки; Prisma CLI оставлен runtime dependency для миграций. Версии фиксируются package-lock.json.
6. Модерация обязательна для публичных персонажей и комментариев. Обычный JWT не даёт доступа к admin API. Каталог, комментарии, follows, likes и новые чаты учитывают блокировку.
7. Экспорт не содержит passwordHash/refresh tokens. Удаление убирает историю пользователя, профиль, сессии, комментарии, подписки, лайки и пользовательские жалобы; покупочные записи сохраняются под обезличенным идентификатором для учёта возвратов.
8. Android хранит сессию и черновик через Keystore AES-GCM. Серверные ключи не входят в APK. Debug cleartext разрешён только для локальной тестовой сети; release требует HTTPS.
9. Логи не включают тексты диалогов, receipt, заголовки авторизации и стек внутренних stream-ошибок. Запросы имеют ограничение размера, rate limits и ограничения очереди.

## Аудит пакетов

Первый `npm audit --omit=dev`: 10 предупреждений (2 critical, 4 high, 4 moderate). Это уязвимости цепочки зависимостей, не доказательство эксплуатации конкретной конфигурации NOVA. Повторный `npm audit --omit=dev`: **0 известных уязвимостей** на дату проверки; это не доказательство отсутствия неизвестных проблем. Снимок результата: `evidence/npm-audit-production.json`. Источники: [fast-jwt security](https://github.com/nearform/fast-jwt/security/advisories), [deepmerge-ts GHSA-ggr8-5vv4-36mx](https://github.com/advisories/GHSA-ggr8-5vv4-36mx), [zod GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5).

## Оставшиеся релизные риски

- Нет независимого аудита и живых магазинных проверок. Доказательства от mock Google API не разрешают включать коммерческие платежи.
- Генерируемый текст ограничен системными инструкциями, но отдельный проверенный классификатор вывода не подключён. Премодерация UGC не заменяет модерацию AI-ответов.
- Нет доказанного backup/restore в production, оповещений дежурного, отработанного восстановления после отказа БД и нагрузки на несколько реплик.
- Глобальный входной rate limiter в памяти процесса; shared PostgreSQL защищает AI-квоты/деньги, но для нескольких API-реплик нужен общий входной limiter или edge gateway.
- Email не подтверждается, CAPTCHA/защита от массовой регистрации и профессиональная антифрод-модель не завершены.
- История и память зашифрованы транспортом при HTTPS; end-to-end encryption диалогов не реализована, PostgreSQL at-rest encryption зависит от хостинга.
- Удаление собственного персонажа каскадно удаляет связанные чаты: требуется продуктовая политика сохранения чужих историй перед открытой авторской платформой.
- У исторических повторов regeneration результат пока не является неизменяемым snapshot; отсутствие повторного списания проверено, точное воспроизведение старого текста после новых регенераций не гарантируется.

## Решение

Коммерческий релиз заблокирован. Монетизация по умолчанию выключена с двух сторон. Публикация в Google Play и реальные платежи в этой работе не выполнялись.

## Дополнение 2026-11-12 (PR #34–38)

Обзор нового кода; это не внешний пентест. Отчёта Gemini Argon в репозитории нет — владелец отменил эту проверку.

Проверено и закрыто тестами:
- Память персонажа приватна для пользователя: чужой аккаунт не читает, не меняет и не удаляет (тест + живой сервер); входит в экспорт и удаляется с аккаунтом.
- Состав группы меняется только на персонажей, видимых пользователю; чужой чат изменить нельзя.
- Автоматическая память не переписывает заметки пользователя; промпт запрещает записывать чувствительные личные данные.
- Статистика автора отдаёт только счётчики; тексты чужих переписок не читаются.
- Страница автора есть только у тех, кто что-то опубликовал; заблокированным она не видна; email не раскрывается.
- Публичная страница `/c/<id>` — только опубликованные персонажи без метки 18+, весь текст экранирован (тест на `<script>`).
- AI Арт: словарный фильтр + проверка запроса моделью, общий дневной предел, списание под блокировкой строки, возврат при сбое.
- Вход: валидация не ослаблена; коды ошибок называют только поле. Блокировка перебора пароля сохранена.
- Ссылка из другого приложения принимается только как UUID и открывает профиль лишь после входа.
- `npm audit --omit=dev`: 0 уязвимостей (2026-11-12).

Новые риски:
- Токен Cloudflare был опубликован в переписке и не перевыпущен (решение владельца). Риск: посторонний может расходовать бесплатную квоту Workers AI аккаунта.
- Автоматическая память и переписывание запросов к AI Арт отправляют фрагменты истории провайдерам бесплатных моделей, как и сам чат.
- Отображаемое имя по умолчанию — часть email до «@»; оно видно у опубликованных персонажей. Нужен экран смены имени.
- Картинки AI Арт проверяются только до генерации; проверки готового изображения нет.
- Голосовой разговор использует службу распознавания телефона (обычно Google): звук обрабатывает она, не NOVA.
