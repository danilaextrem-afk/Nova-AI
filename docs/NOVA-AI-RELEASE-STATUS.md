# NOVA AI — статус выпуска

Дата: 2026-11-11. **Разрабатываемая тестовая сборка; не готовый коммерческий релиз.**

Сохранены main и работа предыдущих разработчиков. PR #12 уже включён в main вместе с исправлениями UI; PR #18 добавил streaming. PR #20 добавляет исправления покупок/приватности, community и дополнительные проверки. Слияние PR #20 допустимо только после успешного финального CI.

## Артефакты

- NOVA-AI-FINAL.apk — имя по запросу владельца; debug-подпись для установки и тестирования. Слово FINAL в имени не означает коммерческую готовность.
- NOVA-AI-RELEASE.aab — release-кандидат **без производственной подписи**, если signing secrets отсутствуют. Нельзя выдавать за готовый Google Play релиз.
- NOVA-AI-FULL-SOURCE.zip — исходники без node_modules и секретов.
- Отчёты TEST-REPORT, MIRAIMIND-COMPARISON, SECURITY-REPORT и этот RELEASE-STATUS содержат ограничения и подтверждённые результаты.

По умолчанию APK не содержит подтверждённого публичного адреса NOVA API. Это устанавливаемая тестовая сборка; работа настоящего AI без развёрнутого сервера и разрешённых ключей не обещается.

## Блокеры

| Блокер | Что должно быть готово перед релизом |
|---|---|
| Хостинг / HTTPS | Подключённый Render или другой управляемый хостинг, PostgreSQL, deploy и проверенный API URL |
| Настоящий AI | Серверные API credentials, проверка условий региона/обработки данных, живые тесты качества и квот |
| Монетизация | Play Console license testers и SKU, Publisher service account, AdMob/SSV/consent, реальные sandbox-тесты |
| Подпись | Производственный signing/upload key и защищённые CI secrets |
| Незавершённые функции | Все открытые требования в матрице из 73 пунктов, особенно AI Art, live voice, локализация, полноценные редакторы/группы/социальные потоки |
| Безопасность и эксплуатация | Output moderation, антиспам регистрации, внешний аудит, нагрузка, backup/restore, monitoring |

Первое необходимое внешнее действие владельца: подключить аккаунт Render к рабочей среде; API-ключи следует хранить в секретах сервера, не присылать в чат. Это откроет этап публичного HTTPS и живых AI-проверок, но не снимает остальные перечисленные блокеры.
