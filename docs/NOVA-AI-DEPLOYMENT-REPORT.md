## Секреты
`DATABASE_URL`, `JWT_SECRET` (случайные 48 байт) и будущий ключ AI хранятся только в переменных окружения Render. В репозитории и APK секретов нет.

## Ограничения бесплатных тарифов
- Render Free: засыпает после 15 минут без запросов, первый запрос после сна ждёт около минуты; 750 часов в месяц на рабочее пространство.
- Neon Free: 1 GB на проект, 100 CU-часов в месяц; вычисления засыпают без нагрузки.
- Groq Free: 30 запросов/мин, 1000 в день, 8K токенов/мин, 200K в день на каждую модель.
- Автодеплой Render из GitHub не подключён (сервис создан по публичной ссылке на репозиторий). Деплой запускаю через Render после слияния; чтобы включить автоматический, владелец может подключить GitHub в настройках Render — не обязательно.

## Ограничение лимитов по IP
За прокси Render все запросы приходят с одного адреса, поэтому лимиты считаются по `True-Client-IP` (`NOVA_CLIENT_IP_HEADER=true-client-ip`), а не по подделываемому `X-Forwarded-For`.
