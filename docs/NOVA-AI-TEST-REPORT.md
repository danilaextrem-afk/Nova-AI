# NOVA AI — отчёт проверок

Дата: 2026-11-11. Коммерческий релиз не одобрен. Исходная стабильная база сохранена, затем включены изменения main через PR #18 и исправления PR #20.

## Подтверждённые результаты

- Локальный TypeScript/Prisma build: PASS после обновления зависимостей.
- Реальная PostgreSQL 18.6, четыре миграции с пустой базы: PASS.
- Vitest: **70/70**, 9 файлов. Реальная БД; HTTP AI и Google Publisher — явные fixtures.
- 100 последовательных Free-сообщений: PASS, баланс не изменяется, сохраняются 200 сообщений; проверена пагинация. Это не 100 обращений к настоящему AI.
- Fallback после 429, timeout, 503: PASS, следующий независимый провайдер получает тот же диалог. Проверены Retry-After, отдельные Groq model buckets, конкурентные квоты, дневной бюджет.
- 10 конкурентных Premium-повторов: одно списание; ошибка AI, незавершённый SSE и неверная цена не списывают токены.
- SSE: последовательность фрагментов, сохранение, запрет продолжать частично показанный ответ другой моделью, отмена без срабатывания breaker, отказ при EOF без завершения.
- Play Publisher fixture: 8 конкурентных повторов после неудачного consume начисляют один пакет; чужая account binding отклоняется; 10 возвратов отменяют покупку один раз.
- SSV: подпись, параметры в подписанной области, отклонение дублирующихся/неподписанных параметров. Настоящего callback от AdMob не было.
- Auth/privacy: возрастное подтверждение, одноразовая ротация refresh и отзыв семейства, блокированный аккаунт, экспорт без секретов, удаление социальных данных, отклонение unsigned/expired JWT, сохранение HTTP 400/413.
- Community: премодерация комментариев, чужое удаление запрещено, admin API изолирован, подписки идемпотентны, фильтрация блокировок, конкурентные лайки.
- Предыдущий полный прогон PR #20: [43092000113](https://github.com/danilaextrem-afk/Nova-AI/actions/runs/43092000113) — backend, Docker, Android builds и **4 Android UI-теста PASS** на коде `cfe2b609a706cb11386b19c0d3ab0b57f3618c10`.

## Финальный прогон ветки

После обновления зависимостей добавлены пятый UI-сценарий сохранения ID запроса после ошибки/перезапуска и второй прогон на экране 480×800 (density 240). Их итог требует проверки нового CI; предыдущие 4 PASS нельзя выдавать за результат этого прогона. Скриншоты сохраняются по абсолютному пути внутри workspace Actions.

Android unit task прежней версии не содержал отдельных JVM-тестов; его успешный exit не считается дополнительным набором unit-тестов. Instrumentation проверяет реальное Android-приложение, но сервер в нём — MockWebServer. Kotlin API/UI и TypeScript backend покрыты разными стендами, полного Android→публичный backend→живой AI E2E пока нет.

## Не выполнено

| Проверка | Причина / точная граница |
|---|---|
| Живые ответы Groq/Gemini/OpenRouter/Cerebras и сравнение русского качества | Серверные ключи и разрешённые квоты не доступны в этой среде |
| Публичный HTTPS, реальный перезапуск сервера, восстановление backup | Нет подключённого хостинга с управлением deployment |
| Google Play license tester/sandbox | Нет доступа к Play Console, тестовым SKU и service account |
| AdMob Rewarded SSV end-to-end, UMP на устройстве | Нет аккаунта/реальных тестовых настроек приложения |
| Производственная подпись AAB | Нет ключа подписи; unsigned-кандидат не является релизом |
| AI Art, live voice, полная социальная платформа | Часть runtime-функций отсутствует; это разработка, не только ключи |
| Масштабная нагрузка и отказ БД | Проверены лишь ограниченные конкурентные сценарии, не capacity benchmark |
| TalkBack/все OEM/все языки | Не проверено |

Исходная причина NetworkOnMainThreadException: reverse DNS внутри `MockWebServer.url()` в `compose.runOnIdle`. Исправление другого разработчика из main сохранено: bind на 127.0.0.1, URL формируется вне UI-потока. Отключения StrictMode/тестов не было.
