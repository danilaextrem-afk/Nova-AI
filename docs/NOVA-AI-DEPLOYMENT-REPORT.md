## Выбранная бесплатная инфраструктура
| Компонент | Сервис | Почему | Ограничения бесплатного тарифа |
|---|---|---|---|
| Backend (Fastify, Docker) | Render Free web service | Уже есть `render.yaml` и Dockerfile; HTTPS и автодеплой из GitHub | Засыпает после 15 мин без запросов, просыпается ~1 мин; 750 ч/мес на рабочее пространство; файловая система временная |
| PostgreSQL | **Neon Free** (не Render Postgres) | Бесплатная база Neon не удаляется; бесплатная Render Postgres истекает через 30 дней | 1 GB на проект, 100 CU-часов/мес на проект, засыпает без нагрузки |
| AI | Groq (gpt-oss-20b → gpt-oss-120b) → OpenRouter `openrouter/free` | Официальные бесплатные квоты, OpenAI-совместимый стриминг | Groq: 30 RPM / 1000 RPD / 8K TPM / 200K TPD на модель; OpenRouter free — меняющийся набор моделей |

Ожидаемые обязательные расходы при тестовой нагрузке: **0 ₽**. При постоянной нагрузке Neon может упереться в 100 CU-часов, а Render — в засыпание; тогда потребуется платный тариф (сообщу заранее, сам не включаю).

## Что нужно для развёртывания (блокер)
1. Подключить коннекторы **Render** и **Neon** в Claude (без банковской карты). Дальше всё делаю сам: создаю базу Neon, сервис Render из `render.yaml`, переменные окружения (`DATABASE_URL`, `JWT_SECRET` генерируется), применяю миграции, проверяю HTTPS, регистрацию, чат и записываю публичный URL в `android/nova-api-url.txt` — следующий APK соберётся уже с ним.
2. Ключ хотя бы одного AI-провайдера (`GROQ_API_KEY` с console.groq.com или `OPENROUTER_API_KEY` с openrouter.ai) — вставить **в панели Render**, не в чат и не в код. Без ключа сервер работает, но честно отвечает «AI не подключён».

## Проверки после развёртывания (план)
HTTPS, `/health`, `/ready`, регистрация, вход, каталог, новый чат, живой ответ модели, история после перезапуска сервиса, ежедневный бонус, реферал, отмена/повтор. Результаты будут добавлены сюда.
